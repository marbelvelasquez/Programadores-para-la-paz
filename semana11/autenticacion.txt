El login es el proceso que permite identificar a un usuario antes de darle acceso a una aplicación.
 Gracias a la autenticación, cada persona puede ingresar con su usuario y contraseña de forma segura.
  Algunas rutas deben estar protegidas porque contienen información privada o funciones que solo pueden usar usuarios autorizados.
   Esto ayuda a evitar accesos no permitidos y protege la información de la comunidad. No se deben exponer públicamente contraseñas,
    documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles.
